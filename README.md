# 🔔 Telegram Bot for Recruiter Reminders (Google Apps Script)

Автоматизированная система напоминаний для тех кто ищет работу. Скрипт анализирует Google Таблицу с откликами на вакансии и автоматически отправляет персонализированные уведомления в Telegram в нужные рабочие дни, подсвечивая строки цветом для визуального контроля.

## 🚀 Возможности
- **Автоматический расчет сроков:** Напоминание ставится на 5-й *рабочий* день после отклика (исключая выходные).
- **Интеграция с Telegram:** Отправка красиво оформленных HTML-сообщений с гиперссылками на вакансию и резюме.
- **Визуальная маркировка:** Автоматическая подсветка строк в таблице (зеленый для ТК РФ, желтый для ГПХ/других).
- **Безопасность и надежность:** Пакетная обработка данных (batch operations) для минимизации лимитов Google Apps Script и ускорения работы.
- **Удобное управление:** Кастомное меню прямо в интерфейсе Google Таблицы для ручного тестирования и настройки триггеров.

## 🛠 Стек технологий
- Google Apps Script (JavaScript ES6+)
- Telegram Bot API
- Google Sheets API (Rich Text Values для извлечения ссылок)

## ⚙️ Установка и настройка

1. Создайте копию Google Таблицы с нужной структурой (колонки A-O: Дата отклика, Ресурс, Ссылка, Позиция, Компания, Контакт, CV, CL, Статус, Причина, Комментарий, Дата напоминания, Напоминание, Тип договора, Навыки). Триггером в таблице является статус **"Ждем ответа"** остальные статусы по желанию.
2. Откройте в таблице **Расширения** → **Apps Script**.
3. Скопируйте код из файла `Code.gs` данного репозитория в редактор скриптов.
4. **Настройка переменных:** В начале файла `Code.gs` укажите ваши данные:
   ```javascript
   const SHEET_NAME = 'Вакансии'; // Имя вашего листа
   const TELEGRAM_BOT_TOKEN = 'ваш_токен_от_botfather';
   const TELEGRAM_CHAT_ID = 'ваш_chat_id';
6. Сохраните проект (💾).
7. Нажмите выполнить для проверки скрипта.
8. Откройте таблицу, обновите страницу. В меню появится пункт 🔔 Напоминания.
9. Для автоматической работы выберите в меню: ⚙️ Создать ежедневный триггер (9:00)
10. **🧪 Тестирование** Проект включает встроенные инструменты для отладки, доступные через кастомное меню:
**Тест 1**: Проверка соединения с Telegram API (валидация токена и chat_id).
**Тест 2**: Отправка реальных данных из первой строки таблицы со статусом "Ждем ответа" для проверки форматирования.
11. **📈 Бизнес-ценность**
- Сокращает время рутинной проверки дат и статусов в таблице.
- Упрощает процесс напоминания. Можно перейти по ссылке на вакансию и напомнить о себе.
- Исключает человеческий фактор (забытые напоминания).
- Не требует платных сторонних сервисов (Zapier, Make), работая полностью в экосистеме Google.
